这是一份参照传统桌面角色扮演游戏（TRPG）与重策社交推理桌游（如《血染钟楼》《阿瓦隆》）体例整理的**严谨版规则说明书**。

---

## 第一章：核心概念与术语定义

在进入游戏前，所有玩家及主持人（Game Master, 以下简称 **GM**）须明确以下核心术语：

### 1.1 玩家状态与标签
* **存活 / 阵亡**：存活玩家享有发言权与投票权；除特定角色技能外，阵亡玩家失去所有行动权、技能与投票权。
* **种族标签**：每个角色拥有且仅拥有一个固定种族标签，分为：
  * **【人类】**：大多数凡人所属种族，能被常规检测机制识别为人类。
  * **【非人】**：非自然或异界存在，无法被判定为人类。
  * **【异人】**：掌握超凡力量的存在，力量一旦施展便无法隐藏。
* **身份公开（暴露）**：当角色触发“公开”状态时，GM 将当场宣布该玩家的具体角色卡，此状态不可逆。

### 1.2 伤害与出局形式
* **公共处决**：通过白昼公决投票、或治安阵营特权直接处决的致死结算。
* **秘密处决**：嗜血者在猎杀阶段发起的致死暗杀结算。

## 第二章：阵营与胜利检定

游戏内共有四大阵营。每一轮结算结束时，GM 均会执行一次**胜利检定**。若多个阵营同时满足条件，按照 **混沌 ＞ 邪恶 ＞ 治安 ＝ 平凡** 的优先级判定胜负。

```
                       [ 阵营关系拓扑 ]
                      
                        ┌───────────┐
                        │  混沌阵营 │ (第三方扰乱者)
                        └─────┬─────┘
                              │ 独赢检定
        ┌─────────────────────┼─────────────────────┐
        ▼                                           ▼
  ┌───────────┐                               ┌───────────┐
  │  平凡阵营 │ ◄─────── 目标对立 ───────►    │  邪恶阵营 │
  └─────┬─────┘                               └───────────┘
        │ (消灭所有非己方)                          ▲
        │                                           │ 治安目标:
        ▼ (潜在协作/胜负互斥)                       │ 诛灭邪恶
  ┌───────────┐                                     │
  │  治安阵营 ├─────────────────────────────────────┘
  └───────────┘
```

### 2.1 平凡阵营（Commoners）
* **阵营构成**：占总玩家基数的 60% 以上，拥有绝对初始票权。
* **胜利条件**：场上存活的所有**邪恶阵营**、**混沌阵营**及**治安阵营**成员全部出局（场上仅余平凡阵营存活）。

### 2.2 邪恶阵营（Evildoers）
* **阵营构成**：由潜伏者与嗜血怪物组成。
* **胜利条件**：场上存活的【嗜血者】数量 **≥ 存活玩家总数的 50%**。

### 2.3 治安阵营（Law Enforcers）
* **阵营特性**：拥有强大的即时制裁与干预权，但**任何成员只要发动特权技能，身份立即公开**。
* **胜利条件**：场上存活的**邪恶阵营**与**混沌阵营**成员被全数消灭。

### 2.4 混沌阵营（Chaos）
* **阵营特性**：不可预测的第三方独立阵营。
* **胜利条件**：当全场存活玩家总数 **≤ 3人** 且**混沌阵营有成员依然存活**时，游戏立即终止，混沌阵营单独获胜。

## 第三章：角色图鉴

---

### 3.1 平凡阵营

#### 【普通人】
* **种族**：人类
* **阵营**：平凡
* **技能【凡夫之身】（被动）**：无特殊能力，依赖公决投票行使权利。

#### 【吹哨人】
* **种族**：人类
* **阵营**：平凡
* **技能【警觉哨音】（信息时·主动）**：每轮信息时，GM 随机指定一名**除自身外**的存活玩家，向吹哨人密报该目标“是人类”或“非人类”。

#### 【验尸官】
* **种族**：人类
* **阵营**：平凡
* **技能【死者遗言】（信息时·主动）**：信息时，可指定一名**历史上被处决（含公共处决与秘密处决）**的阵亡玩家，获取其准确的角色卡信息。每名阵亡者不可被重复查验。

---

### 3.2 邪恶阵营

#### 【嗜血者】
* **种族**：非人
* **阵营**：邪恶
* **协同特性**：游戏开始时，嗜血者之间互知身份。
* **技能【夜幕捕食】（猎杀时·团队主动）**：所有存活嗜血者共同商议，投票密选一名非【嗜血者】玩家进行【秘密处决】。若意见无法统一，则由席位靠前的嗜血者决定；若被圣骑士封印则失去当轮投票权。

#### 【非常者】
* **种族**：人类
* **阵营**：邪恶
* **特性【伪善之面】（被动）**：不参与嗜血者的夜间猎杀频道，不掌握嗜血者队友身份（单向隐藏）；在种族判定上属于**人类**。无主动技能。

---

### 3.3 治安阵营

> *注：治安阵营所有主动技能均在【裁判时】结算，且只要宣告使用，GM 立即翻开其身份牌向全场公开。*

#### 【大法师】
* **种族**：异人
* **阵营**：治安
* **技能【回魂秘术】（裁判时·公开主动）**：
  * **冷却时间**：每 2 轮仅可使用 1 次。
  * **效果**：选定一名阵亡玩家，该玩家立即复活重返游戏，恢复其所有原始机能（含技能、发言权与投票权）。
  * **代价**：首次施放即永久向全场公开大法师身份。

#### 【圣骑士】
* **种族**：异人
* **阵营**：治安
* **技能【誓约裁决/圣佑】（裁判时·公开主动）**：
  * 选定场上一名存活玩家进行守护，产生以下分支判定：
    * **逆转封印**：若目标为【嗜血者】，该目标在紧接的【猎杀时】被剥夺投票与行动权（其伤害无效化）。
    * **绝对庇护**：若目标为非【嗜血者】，该目标在下一轮【裁判时】到来前，免疫所有形式的处决（包含公共处决与秘密处决）。
  * **代价**：施放即向全场公开圣骑士身份。

#### 【圣杀者】
* **种族**：异人
* **阵营**：治安
* **技能【铁腕神裁】（裁判时·公开主动）**：
  * **效果**：越过常规流程，指定场上一名存活玩家立即实施【公共处决】。
  * **代价**：施放即向全场公开圣杀者身份。

---

### 3.4 混沌阵营

#### 【痴呆者】
* **种族**：人类
* **阵营**：混沌
* **特性【混乱思绪】（投票时·强制被动）**：
  * 该玩家不得自主决定公共投票的目标。在【投票时】，其票权必须通过掷骰或 GM 抽签的方式，**完全随机**投向一名合法的存活玩家（包含自身）。

#### 【异星客】
* **种族**：非人
* **阵营**：混沌
* **特性【相位躯壳】（被动）**：
  * 异星客无法被【秘密处决】击杀。若嗜血者在猎杀时指定了异星客，该次猎杀结算自动判定为“落空（平安夜）”。

## 第四章：标准轮次运行流程（Game Loop）

游戏按“轮”（Round）进行，每一轮严格依序执行以下五个阶段：

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1.信息时│ ──► │ 2.辩论时│ ──► │ 3.投票时│ ──► │ 4.裁判时│ ──► │ 5.猎杀时│
└─────────┘     └─────────┘     └─────────┘     └─────────┘     └─────────┘
     ▲                                                               │
     └────────────────────── 下一轮循环 ─────────────────────────────┘
```

### 阶段一：信息时（Information Phase）
1. GM 闭合全场视野或进行暗箱交互。
2. 【吹哨人】接收 GM 私密发放的随机目标人类属性检定报告。
3. 【验尸官】指定目标，接收 GM 私密发放的死亡角色身份信息。

### 阶段二：辩论时（Debate Phase）
1. 全场存活玩家依次进行轮流通话发言（发言顺序由 GM 预定或顺时针轮替）。
2. 合法发言范畴：
   * 提交信息报告 / 阐述逻辑链条
   * 宣告质疑 / 宣布信任
   * 发起指控 / 举证自辩
   * 自主公开身份（禁止主动翻卡自证，允许谎报身份）

### 阶段三：投票时（Voting Phase）
1. 存活玩家对嫌疑目标进行公开点票（痴呆者执行随机掷骰）。
2. **平票决选机制（Tie-Breaker Rule）**：
   * 若产生最高票同票（2人或以上同票），则触发**决选流程**。
   * 全场玩家进行二次表决，选项仅有两项：**【全部处决】** 或 **【全部赦免】**。
   * 取多数票结果执行。若决选二次表决再次平票，则默认判定为**全部赦免**。
3. 被处决者移出游戏，进入阵亡名单。

### 阶段四：裁判时（Adjudication Phase）
治安阵营行动窗口。依下列次序响应：
1. **圣杀者判定**：圣杀者决定是否现身行使【铁腕神裁】。若发动，即时公开身份并移除目标玩家。
2. **圣骑士判定**：圣骑士决定是否现身施放【守护】。若发动，即时公开身份并确立庇护/封印目标。
3. **大法师判定**：大法师检定冷却时间（每2轮一次），决定是否现身复活阵亡者。若发动，即时公开身份并复原目标。

### 阶段五：猎杀时（Hunt Phase）
1. 【嗜血者】建立通讯，密选猎杀目标。
2. **豁免判定**：
   * 若目标受【圣骑士】庇护，猎杀失败。
   * 若目标为【异星客】，触发【相位躯壳】，猎杀失败。
   * 若执行猎杀的嗜血者受【圣骑士】逆转封印，伤害无效。
3. 未被豁免的目标被【秘密处决】，宣告阵亡。
4. 本轮结束，GM 执行**胜利检定**。若无阵营达成胜利，进入下一轮【信息时】。

## 第五章：规则裁判附录与优先级（FAQ）

* **Q1：圣骑士守护了异星客，随后嗜血者袭击了异星客，会怎样？**
  * **裁定**：袭击失败。异星客受自身特质及庇护双重保护。
* **Q2：若圣杀者处决了圣骑士当轮守护的目标，目标会死吗？**
  * **裁定**：目标存活。圣骑士施加的庇护效果优先级高于圣杀者的铁腕神裁（“免疫所有形式处决”）。
* **Q3：验尸官能否查验上一轮刚被圣杀者或嗜血者击杀的角色？**
  * **裁定**：可以。只要在进入【信息时】前已处于阵亡状态的角色，均属于合法验尸目标。
* **Q4：存活人数降至 3 人时，嗜血者比例刚好达到 50%（如 1 嗜血者、1 非常者、1 异星客），谁获胜？**
  * **裁定**：**混沌阵营单独获胜**。依据规则第二章之优先级协议：混沌检定优先于邪恶检定。
